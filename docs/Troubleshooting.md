# Troubleshooting

Here are some solutions to common problems.

## KEY is missing from .env

Ensure you have filled environment variables in the .env file. If you need guidance on how to set up .env, please ask for help.

## Port 8080 is already in use

Close applications that might use port 8080 (e.g., Steam). If you're not sure which process is currently using port 8080, please ask for help.
