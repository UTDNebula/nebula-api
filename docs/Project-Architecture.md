# API Architecture

Nebula API provides UTD data for others to use, including information on courses, professors, events, and more.

## API Overview

Here's a quick look at Nebula API.

### REST API

The Nebula API is a RESTful API. [What's an API? What does RESTful mean?](https://aws.amazon.com/what-is/restful-api/)

Currently, the Nebula API offers information about the following:

- Courses
- Professors
- Sections
- Grades
- Comet Calendar Events
- Mazevo Events
- Astra Events
- Club Events - provided by UTD Clubs
 Rooms
- Discounts

> [!NOTE]
> Nebula API powers only UTD Trends and UTD Rooms. UTD Clubs and Notebook have their own API internal to their own projects. Specifically, the Clubs endpoints are powered by the internal Clubs database.

All of this information (except for club events) is provided by [API tools](https://github.com/UTDNebula/api-tools), which is responsible for scraping, parsing, and uploading the data to a Mongo database.

### How does Nebula API work?

When a user sends a HTTP request, Gin handles the request by matching the URL request to one of our routes.

Then, Gin passes the request's parameters to the appropriate controller. The controller uses those parameters with Mongo's Go Driver to construct a query filter and execute it against the Mongo database.

The database fetches the requested data and then returns the data back to the controller. The controller sends the data and the outcome of the request, in the form of some HTTP status code, back to Gin.

Gin creates a HTTP response with the data and HTTP status code, and finally, Gin sends the HTTP response back to the user.

## API Documentation

We currently use Swagger for our API documentation. Swagger automatically generates documentation for our API routes.

If you make any changes, make sure to run either the Makefile or build.bat to update the documentation.

[Go Mongo Driver Documentation](https://www.mongodb.com/docs/drivers/go/current/) - For using MongoDB with Golang.

Nebula API stores the majority of its data in a MongoDB database. We interact with the Mongo database with the Mongo Go driver.
