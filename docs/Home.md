Join [our community on Discord](https://discord.utdnebula.com) and ask questions in the `#api-help` or the development channels. We are always happy to help!

## Found something you want to change on these docs?

Don't edit these docs manually on Github. Instead, suggest a change by [creating an issue](https://github.com/UTDNebula/nebula-api/issues), or [opening a pull request](https://github.com/UTDNebula/nebula-api/pulls) with your changes.
